# flutter-skills

Small tools I use on real Flutter projects, packaged so you can use them too. Each one lives in its own repo and works as an agent skill for Claude Code or any agent that supports the Agent Skills format, and on its own without an agent.

| Tool | What it does |
| --- | --- |
| [flutter-rtl-audit](https://github.com/TaheBenSaid/flutter-rtl-audit) | Finds the RTL bugs that break your app in Arabic, Hebrew, Persian and Urdu, and fixes the safe ones automatically. |
| [brief-first](https://github.com/TaheBenSaid/brief-first) | Makes your AI coding agent write a plan you can review before it writes any code, then build from it. |
| [flutter-release-check](https://github.com/TaheBenSaid/flutter-release-check) | Catches the release mistakes that stop users from ever seeing your update. |
| [flutter-secure-session](https://github.com/TaheBenSaid/flutter-secure-session) | Finds tokens stored or logged in the wrong place and moves them to secure storage, with a 401 refresh interceptor. |
| [flutter-feature-scaffold](https://github.com/TaheBenSaid/flutter-feature-scaffold) | Starts a feature small and upgrades it to full Clean Architecture in place when it grows. |
| [flutter-ux-details](https://github.com/TaheBenSaid/flutter-ux-details) | Five small UX details (undo, busy buttons, skeletons, optimistic toggles, empty states) with an audit that finds the missing ones. |

Not Flutter-specific, for any stack:

| Tool | What it does |
| --- | --- |
| [pr-self-check](https://github.com/TaheBenSaid/pr-self-check) | Flags secrets, debug leftovers, conflict markers and oversized PRs before your reviewer does. |
| [agent-rules-starter](https://github.com/TaheBenSaid/agent-rules-starter) | A template and examples for the rules file your AI coding agent reads before every task. |
| [kind-code-review](https://github.com/TaheBenSaid/kind-code-review) | Labels, rewrites and a phrasebook for review comments that are clear without hurting. |

I'm adding one tool at a time, each tied to a problem I write about. Watch this repo to hear about the next one.
