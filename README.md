# flutter-skills

Small tools I use on real Flutter projects, packaged so you can use them too. Each one lives in its own repo and works two ways: as a plain Dart script you run from the terminal or in CI, and as an agent skill for any coding agent that supports the Agent Skills format.

| Tool | What it does |
| --- | --- |
| [flutter-rtl-audit](https://github.com/TaheBenSaid/flutter-rtl-audit) | Finds the RTL bugs that break your app in Arabic, Hebrew, Persian and Urdu, and fixes the safe ones automatically. |

I'm adding one tool at a time, each tied to a problem I write about. Watch this repo to hear about the next one.
